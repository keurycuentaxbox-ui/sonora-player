Sobre SONORA

Este prototipo busca música mediante la API de Jamendo, una plataforma de música independiente. No incluye todo el catálogo comercial de Apple Music.

El botón de descarga solo aparece cuando Jamendo indica que el artista permite descargar esa canción. La descarga se realiza desde el servicio original.

Esta versión web no garantiza reproducción con el iPhone bloqueado ni almacenamiento permanente de archivos dentro de SONORA. Para una experiencia más fiable se necesitaría una app nativa.
